# 사이클 2 노트 — 계측 top88: 국소 승수 법칙의 실측

**프로젝트:** SIMP 위상최적화 동역학의 통계역학 계측 / 이론 병행 트랙
**날짜:** 2026-08-16 · **상태:** 사이클 2 완료 (top88 실측 — 법칙 성립, 새 현상 3건 발견)
**설정:** 60×20 MBB, volfrac 0.5, p=3, move 0.2, 감도필터, rmin ∈ {1.1, 2.4}, η ∈ [0.3, 1.6] (0.1 간격), 200 반복 + 34 반복 섭동 프로브. 스크립트: `top88_instrumented.py`(스윕), `probe_experiment.py`(고정 설계 프로브).

> 정정 사항: 사이클 1 노트의 통합 승수식은 μ_loc = 1 − η·s (s = −∂log D/∂log x)로 수정됨. 직렬 토이 s=p+1, 병렬 토이 s=−(p−1)와 정합.

---

## 1. 계측기

자유집합(경계·이동제한에 걸리지 않은 원소)에서, 로그좌표 증분 dz_k = log x_{k+1} − log x_k 와 감도 증분 Δlog D̃를 **중심화**(평균 제거 — λ/부피 방향 소거)하여:

- **지배 승수** μ̂ = ⟨c(dz_k), c(dz_{k−1})⟩ / ‖c(dz_{k−1})‖² (거듭제곱 반복 원리)
- **방향 강성** ŝ = −⟨c(Δlog D̃), c(dz)⟩ / ‖c(dz)‖²
- 순수 곱셈 갱신이면 자유집합에서 **항등식 μ̂ = 1 − η·ŝ** 가 성립해야 함
- 안정 영역에서 flip 모드가 크립에 가려지므로: **섭동 프로브**(수렴 설계에 log-섭동 0.05 주입) + **2단계 소거 추정기**(늦은 창에서 지배근 → 소거 잔차의 이른 창 상관으로 둘째 근), 시드 3개 중앙값

## 2. 결과

**(a) 법칙이 실제 코드에서 성립.** 클리핑·이동제한·λ 이분법·감도필터·FE 결합이 전부 켜진 top88에서, 자유집합의 μ̂와 1−η·ŝ가 **28개 실행 전 구간에서 소수점 3자리 일치** (fig_cycle2 C). 토이의 항등식이 실전 코드 경로에서 살아남았다.

**(b) 온셋은 정정계 하한을 지킨다.** 진동 시작(진폭>3×10⁻³ 및 μ̂<−0.5): rmin=1.1 → **(0.8, 0.9]** (완만한 성장), rmin=2.4 → **(0.6, 0.7]** (급격한 점프). 둘 다 사이클 1의 하한 **η\* ≥ 2/(p+1) = 0.5** 위 — s ≤ p+1 예측과 부합. 표준 η=0.5가 안전한 이유가 정량화됨.

**(c) 발견 1 — 포화 진동은 한계 안정선에 자기조직화.** 이동제한에 포화된 2-주기에서 μ̂ = −1.000, 그리고 **ŝ = 2/η 정확히** (η=1.0→1.996, 1.2→1.667, 1.6→1.250). 시스템이 ηs=2 한계선 위에 앉는다 — 임계 기울기에 앉는 모래더미와 같은 구조. 본 프로젝트(통계역학 계측)의 관측량 후보.

**(d) 발견 2 — 필터 역설.** 큰 필터(rmin=2.4)가 작은 필터(1.1)보다 **더 일찍**(η 0.6–0.7 vs 0.8–0.9) 불안정해지고, 진동 시 품질 파괴도 크다: 컴플라이언스 216.7 → 346 (**~60% 악화**) vs 195.6 → 202.6 (~3.5%). 진동은 "느린 수렴"이 아니라 **나쁜 설계로의 고착**이다 (fig_cycle2 E·F: 특정 부재에 국소화된 진동).

**(e) 발견 3 — 설계 자기안정화의 증거.** 고정 설계 프로브(η=0.5 수렴 설계 x₀에 η만 바꿔 찌름 — OC 고정점은 η-불변이므로 같은 야코비안을 다른 η로 측정):

| | flip 근 (프로브) | 문턱 (연속 실행) | 외삽 교차 |
|---|---|---|---|
| rmin=1.1 | +0.65(η.3) → −0.37(η.5) → 포화(η.6~) | **(0.5, 0.6]** | 0.61 ✓ |
| rmin=2.4 | +0.60 → −0.53(η.6) → 포화(η.7~) | **(0.6, 0.7]** | 0.78 (~0.1 과대) |

핵심 대조: rmin=1.1의 **고정 설계 문턱(0.5–0.6)이 full-run 온셋(0.8–0.9)보다 훨씬 낮다.** 즉 η=0.6–0.8로 처음부터 돌리면 최적화가 x₀와 다른, s가 낮은 설계로 흘러가 안정을 유지한다 — **설계가 ηs<2를 만족하도록 적응하다가, 더는 불가능한 η에서 전역 온셋이 발생한다**는 가설. rmin=2.4는 고정 설계와 full-run 문턱이 일치(0.6–0.7) — 강한 필터에서는 적응할 여지가 없음. 필터 역설(d)의 유력한 설명 후보.

## 3. 추정기의 한계 (정직성)

- 고정 설계 프로브의 μ(η) 점들이 직선이 아니라 **아래로 볼록한 포락선**을 그림(선형 fit 절편이 이론값 1을 초과: 2.10, 1.90). 해석: 야코비안에는 s가 다른 **모드 스펙트럼**이 있고, 프로브는 η마다 가장 눈에 띄는 모드를 잡는다. 낮은 η에서는 s 작은 모드, 문턱 근처에서 s_max 모드. 외삽 과대추정(특히 rmin=2.4)의 원인.
- 크립 모드(μ̂≈+1, ŝ≈0)의 정체 미해결 — 회색 경계 원소의 느린 비선형 드리프트로 추정.
- 단일 문제(60×20 MBB)·단일 volfrac·감도필터 한정, η 격자 0.1, 프로브 진폭 0.05의 약한 비선형 오염 가능.

## 4. 사이클 3 후보

1. **야코비안 직접 스펙트럼 (추천):** 설계 고정 + OC 1스텝 선형화의 J·v를 유한차분으로 구현, Lanczos/ARPACK으로 s-스펙트럼과 고유모드의 **공간 구조** 측정. 포락선 문제 해소, 절편=1 직접 검증, "어느 부재가 위험한가"의 지도.
2. 자기안정화 가설 정량화: full-run 설계들의 s_max(η) 궤적 추적 — "ηs_max가 2에 머무는가?"
3. 필터 역설 해명: 감도필터의 1/x 인자와 모드 공간 구조가 s_max에 미치는 효과 계산.
4. 밀도필터·투영과 비교, 다른 BC·메시에서 재현.
