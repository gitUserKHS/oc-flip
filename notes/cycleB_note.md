# 사이클 B 노트 — AIMD 적응 감쇠: 최소 구현 성공

**날짜:** 2026-08-16 · **판정: 성공.** 단일 상수 세트(전 런 공통)로 세 시작점(η₀ = 0.3/0.5/1.0) × 두 구성(r1.1/r2.4) 전부 수렴, 과구동 런 구조, η가 구성별 문턱을 자동 발견. **"c는 문제 무관, η는 문제 의존"의 최소 실증.**

재현: `python src/cb_aimd.py 400` (~80초). 데이터 `data/cb_aimd.npz`, 그림 `figs/fig_cycleB.png` (`src/cb_fig.py`).

---

## 1. 규칙 (사이클 A 게이트에서 도출)

```
워밍업(25스텝, η 고정) 후 매 스텝:
  μ̂_w < −(1−δ) and ŝ_w > 0.1 :  η ← c/ŝ_w   (MD, 즉시; 쿨다운 5)
  amp_w < 1e-3               :  η 유지        (크립 바닥 — 탐색 무의미)
  그 외                       :  η ← η + α    (AI, 천천히)
```

**전 런 공통 상수**: c=1.7, δ=0.25, α=0.01/스텝, 워밍업 25, 창 4(중앙값), 쿨다운 5, 동결 amp 1e-3, η∈[0.05,1.9]. 추정기는 사이클 2 정의(내부 마스크, 중심화), ŝ은 μ̂ 게이트 하에서만 사용(함정 12).

**설계 정합 2건 (파라미터 튜닝 이력 — 정직 기록):**
- δ=0.1 초판은 실패: 부분 적응된 약진동에서 μ̂≈−0.8이 게이트(−0.9)를 못 넘겨 AI가 η=1.14까지 폭주(P1 η₀=1.0). δ=0.25로 완화하되 **c와 정합 필수**: MD 직후 μ = 1−c = −0.7이 게이트(−0.75) 밖이라 재발화 없음.
- 동결 없던 초판은 수렴 후에도 AI가 경계를 재탐사해 소진폭 진동 잔류(P2). **바닥 동결은 이론 귀결**: amp가 크립 바닥이면 잔여 모드는 s≈0이라 η가 아무것도 못 사줌(사이클 A 스펙트럼 형상).

## 3. 판독

1. **구조 데모 (P2, η₀=1.0)**: 고정 1.0은 컴플라이언스 330→313(+44%) 파괴 지속; AIMD는 t≈120에 이미 217 계열로 회복(comp@200 216.74), 400에서 fixed 0.5·사다리와 3자리 동률.
2. **η 자동 안착**: 시작 3배 산포(0.3–1.0)에도 η_end가 구성별로 몰림 — P1 {0.482–0.510} (η\*=0.503 근방), P2 {0.567–0.583} (η\*≈0.6 직하). 문턱을 아는 사람 없이 문턱을 찾음.
3. **과감쇠 보너스 (P1, η₀=0.3)**: AI가 0.3→0.51로 끌어올리며 comp 194.62 — 고정 0.5(195.61)보다 좋음. 벌크 가속 + 용량 적응 경로의 이득.
4. **무해성 (η₀=0.5)**: fixed 0.5 대비 +0.1% 이내.
5. **정직한 비용**: η₀=1.0 회복은 ~300반복 (P1은 중간에 η≈1.1까지 재상승 — 설계가 고η에서 부분 적응하며 문턱 자체가 이동(용량 적응)해 AI가 추격; 이후 MD 연쇄로 하강·완전 수렴 amp 7e-8). 200 예산에서는 잔류 과도.

## 4. 한계 · 사이클 C로

- 구성 2개·시드 1개·p=3 한정 — 스윕(메시/BC/vf/p/rmin) + **튜닝 실패율 표**는 C.
- Anderson(li2020fixedpoint) 조합 데모, MMA 열, 논문 재편(제목·기여 4개·§5.8 부록화)도 C.
- 사다리 베이스라인이 이 두 구성에선 무의미(발동 안 함) — C 스윕에서 발동 케이스 포함 필요 (예: 고η 시작 사다리).
- freeze_amp=1e-3은 60×20 크립 스케일 기준 — 메시 의존성 확인 필요 (C).

## 5. 함정 등재 (CLAUDE.md 14)

14. **AIMD 상수는 서로 정합해야 한다**: (a) MD 직후 승수 1−c가 게이트 −(1−δ) 밖이어야 재발화 루프가 없다 (c=1.7 ⟺ δ<0.3). (b) 수렴 후 AI는 동결 — 바닥 amp에서 잔여 모드는 s≈0이라 η 탐색은 진동만 재도입. (c) 약진동(부분 적응) 케이스가 게이트 문턱을 결정 — δ는 포화 μ̂=−1이 아니라 온셋 μ̂≈−0.7~−0.8 기준으로.
