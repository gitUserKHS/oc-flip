## 1. A-i — 궤적 ŝ의 이중 국면 (AIMD 규칙의 전제)

60×20 MBB p=3, rmin ∈ {1.1, 2.4} × η ∈ [0.3, 1.6] (28런, 200반복, 사이클 2 스윕 재현 + ŝ 계측):

| 국면 | ŝ 판독값 | 의미 |
|---|---|---|
| 수렴 (η < 온셋) | **[−0.04, +0.15]** (rmin1.1 η≤0.7), [0.005, 0.02] (rmin2.4 η≤0.5) | **s≈0 크립 가장자리** — s_max(3.97/3.36)와 무관 |
| 전이대 (온셋 직하) | μ̂ 부호가 −로 꺾이며 ŝ 점프 (η=0.8: μ̂=−0.43, ŝ=1.78; rmin2.4 η=0.6: μ̂=−0.01, ŝ=1.69) | 부호 신호 = 게이트 |
| 포화 진동 | **η·ŝ = 2.000 (3–4자리), 14/14런** (ŝ_mid도 동일) | 사이클 2의 3점 → 14점 확장; ŝ = 2/η |

- **naive η = c/ŝ 발산 확정**: 수렴 국면 ŝ은 0 근방(음수 포함) → c/ŝ → ±∞. mid-density 마스크(0.05<x<0.95)도 수렴 국면에서는 못 구함 (ŝ_mid ≈ 0.003–0.49).
- **AIMD 구조 정당화**: flip 활성(μ̂<0) 시에만 ŝ 사용 — 온셋 근방에선 ŝ ≈ s_max(정확한 점프폭), 포화에선 ŝ = 2/η라 η ← c/ŝ = (c/2)·η의 **기하 백오프** (s_max 몰라도 작동). 안정 구간은 additive increase.
- **순환성 지적 수용**: μ̂ = 1−ηŝ 항등식(사이클 2, 28런 3자리)은 곱셈 구조의 검증이지 "ŝ이 s_max를 읽는다"의 증거가 아님 — 같은 궤적에서 나오므로 어느 모드를 읽든 성립. 어느 모드를 읽는지는 본 스윕이 규명 (국면 의존). 논문 §5.1에 명시.

## 2. A-ii — 리처드슨 최적점 = flip 경계 (18/18 스펙트럼)

각 실측 스펙트럼(V3·V4 + p-스윕 ref/adapt 16개, 저장 x0에서 J 재구성)에서 양수 가지에 대해 수치 argmin_η max_m |1−η·s_m| 계산:

- **닫힌형 일치**: 수치 최적 = 2/(a+b) 4자리 일치 전 케이스 (a = 최소 양수 s, b = s_max). 극값 지배 확인.
- **스펙트럼 형상 보편**: 하단 가장자리 a ∈ [0.004, 0.12] (p5_adapt만 0.24), **벌크 중앙값 s_med = 0.95–1.0 전 케이스** — 리뷰 관찰("질량은 s≈1, 하단은 0") 그대로.
- **a/b ≤ 0.02** (17/18; p5_adapt 0.069) ⟹ **η_opt가 η\* = 2/s_max와 1–2% 이내 일치**. 하단이 0에 붙는 스펙트럼에서는 min-max 최적이 flip 경계에 붙을 수밖에 없음.
- **R0 (p3.0_ref): η_opt = 0.4990** vs folklore 0.5 (0.2% 차) vs η\* 0.503. **"marginality는 위험 신호가 아니라 최적성의 서명."**
- **folklore 양면 통합**: "smaller exponents are more stable but slower"의 but slower = 벌크(s≈1) 감쇠율 |1−η| — η 0.5→0.25에서 스텝당 0.5→0.75, 100반복이면 잔차 4×10¹⁷배 차이. 트레이드오프 하나, 상수 하나.

## 6. 함정 등재 (CLAUDE.md 12·13)

12. **naive η=c/ŝ은 발산한다** — 수렴 국면의 ŝ은 s_max가 아니라 s≈0 크립 가장자리를 읽음 (실측 [−0.04, +0.15]). 반드시 μ̂ 부호로 게이트.
13. **μ̂=1−ηŝ 항등식은 추정기 검증이 아니다** — 같은 궤적에서 나온 두 추정기라 어느 모드에서든 성립(순환). 프레임워크 검증으로만 인용.
