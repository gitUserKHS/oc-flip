**킬 조건 미발동.** 감쇠 OC의 국소 분기(진동) 해석은 문헌에 완결되어 있지 않다.

| OC 진동 현상 + 고정점 관점 + Anderson mixing 가속 | Li (Paulino group) MS thesis 2018 |

**공백의 근거:** SiMPL 저자들(2024)은 OC를 "휴리스틱이며 이론적 기반이 아직 개발 중"이라 쓰며 Ananiev만 인용. Li–Paulino는 자신들의 안정화 논증을 "부분적 설명"으로 한정. 즉 **감쇠 OC를 곱셈형(EG형) 동역학계로 보고 국소 승수·flip 문턱을 유도해 실측과 대조**하는 작업은 미점유.

**미결:** Martínez 2005 수렴 노트 원문 미확인(함수값 수렴 계열로 추정 — 사이클 2에서 확인). 감도필터 변분 구조 논쟁(gate 4)은 토이에 필터가 없어 보류. 관련 실마리: consistent operator splitting (arXiv:1307.5100)이 필터 유사 업데이트를 유도함.

## 1. 설정 — 정정계 SIMP 토이와 순수 OC 사상

원소 e=1..n, 밀도 x_e ∈ (0,1], 정정계(힘 재분배 없음)라 원소별 계수 a_e>0 고정:

- 컴플라이언스: c(x) = Σ_e a_e x_e^(−p)
- 민감도: D_e = −∂c/∂x_e = p a_e x_e^(−(p+1)) > 0
- **순수 OC** (이동제한·클리핑 없음, 부피 등식 Σx = V):
  x_e⁺ = V · x_e D_e^η / Σ_j x_j D_j^η

λ는 정규화로 소거된다. 감쇠 지수 η가 유일한 알고리즘 파라미터.

## 2. 명제 1 (정확 선형성과 flip 문턱)

상대 로그좌표 z = log(x_1/x_2) (일반 n에서는 z_ef = log(x_e/x_f))에서 순수 OC 사상은 **정확히 아핀**이다:

> **z⁺ = μ z + (1−μ) z\*,  μ = 1 − η(p+1)**

여기서 z\* = log(a_1/a_2)/(p+1), 즉 KKT점 x\* ∝ a^(1/(p+1)).

**증명 스케치.** x_e D_e^η = p^η a_e^η x_e^(1−η(p+1)). 정규화 분모는 모든 e에 공통이므로 비율에서 소거. 따라서 z⁺ = η log(a_1/a_2) + μ z. ∎

**따름정리 (n원소 일반화).** 로그좌표 야코비안은 J = μ(I − 1wᵀ) (w = x\*/V). 고유값은 0 (부피 방향, 정규화가 소거) 과 **μ (중복도 n−1)**. 즉:

1. **수렴역:** 0 < η < 2/(p+1) 이면 임의 내부 초기값에서 비율 |μ|로 전역 기하수렴
2. **1-스텝 수렴:** η = 1/(p+1) 이면 μ=0, 한 번의 반복으로 정확히 도달
3. **flip 경계:** η = 2/(p+1) 에서 μ = −1 — 전 위상공간이 중립 2-주기
4. **초과 시:** η > 2/(p+1) 이면 발산 → 실장 코드에선 이동제한·경계로 유계 진동에 포화

**핵심 관찰:** 표준 조합 **(p, η) = (3, ½)은 정확히 flip 경계 위**(μ = −1). p=1, η=½은 μ=0 — 고전 fully stressed design의 1-스텝 수렴을 복원(유도의 정합성 방증).

## 3. 명제 2 (병렬 토이 — 다른 종류의 불안정성)

병렬 2-바: c = F²/Σ a_e x_e^p, D_e = p a_e x_e^(p−1) F²/(Σa x^p)². 같은 계산으로

> **z⁺ = (1 + η(p−1)) z**  (정확)

p>1이면 내부 대칭점은 **반발**(μ>1) — 진동이 아니라 승자독식으로 단조 탈출(bang-bang). p=1은 중립(퇴화: c가 Σx에만 의존). **교훈:** OC의 병리는 최소 두 종류 — 감쇠 부족에 의한 flip 진동(직렬형)과 양의 되먹임에 의한 경쟁 발산(병렬형). 실제 구조에선 두 메커니즘이 s_e = −∂log D_e/∂log x_e 의 국소값으로 통합된다: **μ_loc ≈ 1 − η·s, s>0이면 flip 위험(η가 크면), s<0이면 경쟁 위험.** (직렬 토이 s=p+1, 병렬 토이 s=−(p−1)로 두 명제와 정합)

## 4. 실험 결과 (fig_cycle1.png)

설정: a=[1,2], V=1.2, 경계 [10⁻³,1], top88-변형은 λ 이분법+클리핑+이동제한 m 포함.

- **(A) 수렴률:** 실측 수축률 vs 예측 |μ| — 순수 OC와 top88-변형 모두 최대 오차 **~6×10⁻⁷** (p∈{1,3,5}, η 전 구간). η=1/(p+1) 1-스텝 수렴 실측 |z₁−z\*| = 5.6×10⁻¹⁷.
- **(B) 분기도 (p=3, m=0.05):** 단일 가지가 **정확히 η=0.5에서** 두 가지로 갈라짐. 문턱 직하(η≈0.475) 진폭 10⁻¹⁵, 직상(η≈0.525) 진폭 0.2(이동제한 포화).
- **(C) (η,p) 진폭 지도:** 진동/수렴 경계가 이론 곡선 **η\*=2/(p+1)** 을 그대로 추적.
- **(D) 병렬 토이 (p=3, η=½):** 실측 z-승수 **2.000** (예측 1+η(p−1)=2), 6스텝 만에 bang-bang [1.0, 0.2] 도달.

**이동제한·클리핑 불변성:** 내부 고정점 근방에서 두 장치 모두 비활성이므로 국소 승수와 문턱은 불변 — 실험 (A)(B)(C)가 확인. 이동제한은 문턱 이후의 **진폭만** 결정(m-핑퐁).

## 5. 논의 — 자리매김

1. **OC = "로그-민감도 EG".** x⁺ = x·exp(η log(D/λ)) 로 쓰면 exponentiated gradient에서 그래디언트 자리에 로그-민감도가 들어간 형태. 이 로그화가 D의 곱셈 스케일 불변성을 주며, OC가 스텝사이즈 튜닝 없이 도는 이유를 설명한다.
2. **SiMPL과의 기하 대비.** SiMPL의 미러 맵은 Fermi–Dirac(경계 0과 1 양쪽을 부드럽게 인지), OC는 한쪽 로그 기하 + 상한은 클리핑. "OC의 취약성은 기하가 x=1을 모르는 데서 온다"는 서사가 성립 가능 — 이후 검증 대상.
3. **s가 다리다.** 실제 top88(부정정+필터)에서는 s_e ≠ p+1이고 상태 의존적. **계측 트랙이 궤적에서 s와 지배 승수를 추정**하고, 이론 트랙이 μ_loc = 1−η·s로 문턱을 예측 — 두 트랙이 같은 코드 위에서 맞붙는 구조가 사이클 1에서 성립했다.
