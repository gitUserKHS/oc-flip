- 사이클 3–4의 균일도 휴리스틱은 정확 사영과 3자리 이상 일치 — 사후 정당화 완료. 논문은 정확 사영으로 서술, 휴리스틱은 각주.

## 2. 실험 B — 음수 가지의 정체와 종결 (백로그 2 마감)

V3 캔틸레버, 정확 사영 s_min = −0.04308, 모드 킥 δ=0.005, η=0.5, 3000반복 (`c5_run.py negbranch`).

- **성장률 4자리 일치**: μ 실측 1.0215 vs 예측 1−ηs_min = 1.0215 (n=76 비율 중앙값).
- **정체 = 거울쌍 대칭 파괴 (winner-take-all의 문자적 실현)**: 서포트 상위 20개가 전부 캔틸레버 상하 거울 쌍(v 성분 정확히 ±짝, x₀ 동일값; |v|²의 77%가 x<0.05). 모드는 쌍 내부의 반대칭 재배분 — 병렬 토이의 s<0 가지가 대칭쌍 좌표에서 야생 출현한 것.
- **궤적**: 지수 성장(피크의 1%→99%가 t=98→409) → 승자 0.009→0.032 / 패자 →0.002 (바닥 근방) → 재정착. amp 1.9e-7 → 1.1e-11 (t≈600 이후 완전 정착).
- **종결 방식 — 예상 정정**: XMIN 정확 흡수 0개, 자유집합 이탈 4개 (352→348). 리뷰 대응 노트의 "XMIN 흡수 종결 예상"은 반증 — 실제는 **인접 비대칭 고정점으로의 재정착**. 초기 대칭해는 엄밀히 안장점.
- **종결 후 스펙트럼**: s_min = **+0.0375** (음수 가지 소멸), s_max 3.486→3.466. 경쟁이 해소되면 음수 모드가 스펙트럼에서 제거됨 — p=5에서 s_min>0인 것과 동일 기제.
- 컴플라이언스 180.56→180.52 (−0.02%): 대칭 안장 탈출이 품질을 해치지 않음 (미세 개선).

**(a) "p=5 이탈" 반증.** 기준 프로토콜에서 s_max = 5.969, 포화율 0.995 — **포화 법칙 s_max→p+1은 p∈[1.5,5] 전 구간에서 경계 없이 성립** (포화율 0.96–0.995). 프리뷰의 4.330은 법칙의 경계가 아니라 **또 다른 고정점**이었음 (수렴 경로 미문서화의 산물 — 함정 10).

**(b) 자기제한(적응 천장): 프로토콜이 p=3에서 정확히 갈라짐.** 적응 프로토콜은 p≤3에서 기준과 동일 고정점, p>3에서 s_max ∈ [3.26, 3.84] — 전부 천장 2/η₀ = 4 아래. 갈림 조건 p+1 = 2/η₀ ⇔ **p=3 (η₀=½)**: 표준 쌍 (3, ½)은 "동역학이 자연 고정점(p+1 포화)을 그대로 수렴시킬 수 있는 최대 p"라는 세 번째 특성화를 얻음. η=½ 실무가 p>3에서도 "그럭저럭 되는" 이유 = 동역학이 자기가 안정한(s_max<2/η) 고정점으로 표류하는 생존자 편향 — 사이클 2c "용량 적응"의 스윕 전체 실증.

**(c) 문턱은 고정점의 성질 (최강 판별).** 같은 p=5 문제에서 기준 고정점(s_max 5.969)의 온셋은 (0.300,0.370] ∋ 0.335, 적응 고정점(3.519)의 온셋은 (0.528,0.608] ∋ 0.568 — **각자 자기 2/s_max를 따름**. μ-법칙이 고정점 선택과 독립으로 성립. "η\* = 2/s_max is a property of the fixed point the dynamics has selected, not of (p, mesh)."

**(d) 비율 법칙 42점 검증.** 두 프로토콜 합산, flip-모드 활성(signed<0) 프로브 42점에서 실측 |r| vs 예측 |1−η·s_max| **중앙편차 0.001** (문턱 직상 첫 점들까지 3자리: 1.208/1.208, 1.218/1.218, …; 문턱 위 둘째 점부터는 클리핑 포화로 계획된 이탈).

복소 모드: p=1.5만 상위 켤레쌍 2.403±0.009j — 보정 문턱 2Re/|s|² = 0.832 = 2/s_max (3자리 동일). 나머지 전부 실수.

## 4. 실험 C2 — 기제: "회색층 두께" 기각, "필터 detuning" 채택

p=5·p=3 × rmin ∈ {1.1, 1.5, 2.0, 2.4} (기준 프로토콜):

| rmin | s_max (p=5) | s_max (p=3) |
|---|---|---|
| 1.1 | 5.969 | 3.976 |
| 1.5 | 3.893 | 3.261 |
| 2.0 | 3.421 | 3.031 |
| 2.4 | 2.954 | 3.359 |

- 회색 원소 수는 rmin과 대체로 증가(p=5: 237→225→263→362)하는데 s_max는 **감소** — "회색층 두꺼울수록 정정 하위구조 발달" 가설 **기각**.
- 대신: **감도필터 반경이 국소 정정 하위구조를 공간 평균으로 detune**하며, 민감도는 p가 클수록 큼 (p=5 −50% vs p=3 −15~24%, 비단조 꼬리). 구조가 bang-bang화될수록 위험 모드가 국소화 → 필터에 취약. V5 밀도필터(s_max 0.37)로 이어지는 **연속 스펙트럼**: 필터링 강도(유형×반경)가 flip 가지를 단계적으로 해체.
- 실무 지침 강화: η 낮추기, 밀도필터 전환에 이어 **감도필터라도 반경을 키우면 문턱 여유 확보** (p=5, r2.4: η\*=0.677).

## 6. 논문 반영 (골격 패치 v3)

1. §4에 정확 사영 정의 + 행-널 실측 + s=2/η 아티팩트 한 단락. 휴리스틱은 각주로 강등.
2. §5.7 (p-스윕): 두 프로토콜 표 + Fig5c/d/e. 헤드라인 "saturation holds across p∈[1.5,5]; the standard pair (3,½) is the largest p whose saturated fixed point standard damping can still reach" — 기여 목록의 p-스윕 항목을 이 문장으로 교체.
3. §5.8 (음수 가지): 대칭 파괴 서사 + Fig5a/b. "terminates by resettling into a nearby asymmetric fixed point whose spectrum has shed the negative eigenvalue (clipping absorption is not required)".
4. §5.6 (필터): V5 브래킷 (5.4,6.0] + rmin detuning 시리즈 (Fig5f). "strongly detunes" 문구 유지, 이제 정량 지지.
5. §6 Discussion에 "fixed-point landscape" 소절: 다중 고정점의 s_max 분포(5.97/4.33/3.52가 같은 문제에서 관측), 프로토콜 명시 의무. 통계역학 2편 씨앗.
6. §7 Limitations 갱신: p=5 경계 문구 삭제; adapted p=4.0 프로브 예외; V5 브래킷 폭 0.6; rmin 비단조 꼬리(p=3, r2.4) 미해명.
